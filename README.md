# Bulela Gomoshe Portfolio

React portfolio for Bulela Gomoshe, a Cape Town full-stack developer building websites, online stores, and business web tools for small businesses.

## Tech Stack

- React
- React Bootstrap
- React Icons
- Framer Motion
- Formspree contact form

## Sections

- Hero with service positioning and WhatsApp CTA
- About, skills, timeline, and hackathon proof
- Project gallery with live links
- Events gallery
- Contact form with WhatsApp and email fallback

## Local Development

```bash
npm install
npm start
```

Open `http://localhost:3000`.

## QA

```bash
npm test -- --watchAll=false
npm run build
```

The production build is generated in `build`.

## Technical Roadmap

- Replace Create React App with Vite to remove CRA maintenance warnings and improve local build speed.

## Deployment

Deploy the `build` folder to a static host such as Netlify, Vercel, or GitHub Pages. This repo currently has no deploy script or hosting config checked in.
